# 水墨风 UI 增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有线条+毛玻璃双主题体系上，通过新增"墨韵" token 族将抽象水墨质感（墨晕背景、纸纹、朱砂情感色、晕染边缘）应用到背景、控件与阅读正文三层。

**Architecture:** 全部为新增 token + 样式应用，现有 token 不改名不改值。阅读正文层经 `themeStyles`（`src/types/index.ts`，三适配器共用注入）添加纸纹与章节朱砂小印；应用背景经 `src/utils/styles.ts` 默认预设与 `App.tsx` 背景过渡层实现。

**Tech Stack:** CSS custom properties（双主题 `[data-ui-theme="glass"|"flat"]`）、内联 SVG data-URI（feTurbulence 纸纹）、React 18 + TypeScript、Vitest。

**Spec:** `docs/superpowers/specs/2026-07-31-ink-wash-design.md`

## Global Constraints

- 现有 token（`--ink-*`、`--accent`、`--warn`、`--danger`、`--bg-*`）一律不改名、不改值；全部改动为新增
- 双主题各自定义墨韵 token：暗夜书房 `:root, [data-ui-theme="glass"]`、日间图书馆 `[data-ui-theme="flat"]`
- 不新增 npm 依赖；不新增 backdrop-filter 元素（现有毛玻璃数量不变）
- 旧高亮兼容：已存库高亮颜色值不动，仅新建高亮使用新色板
- 用户自定义背景（`customBgConfig` 图片/渐变）与自定义阅读主题（`customTheme.ts`）**不受影响**
- 语义色规则：信息层→墨青 `--accent`；情感层→朱砂 `--seal`；警示→`--warn`；破坏→`--danger`
- 纸纹噪点 SVG 通用编码（本计划所有 `--paper-texture`/预设/themeStyles 均用此形式，仅 opacity 不同）：
  `url("data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 width=%22200%22 height=%22200%22%3E%3Cfilter id=%22n%22%3E%3CfeTurbulence type=%22fractalNoise%22 baseFrequency=%220.9%22 numOctaves=%222%22 stitchTiles=%22stitch%22/%3E%3C/filter%3E%3Crect width=%22200%22 height=%22200%22 filter=%22url(%23n)%22 opacity=%22OP%22/%3E%3C/svg%3E")`（OP 替换为 0.10/0.07/0.08）

### Task 8: 主题切换墨色流动过渡（App.tsx）

**Files:**
- Modify: `src/App.tsx`（根组件；新增 2 个 state + 1 个 ref + 1 个 useEffect + 根 div 内新增一层绝对定位 wash 层）
- Modify: `src/styles/theme.css`（追加 `.app-bg-wash` 与 `@keyframes`）

**Interfaces:**
- Consumes: `appBg`（现有 useMemo 结果，`src/App.tsx:214-241`）
- Produces: 根 div 背景改为 `displayedBg`；新增 `.app-bg-wash` 层承载新背景并 0.3s 淡入

背景过渡机制（spec §8）：CSS transition 对渐变不插值，因此用"旧背景垫底 + 新背景层淡入"实现墨色晕开换场：

- [ ] **Step 1: 新增状态与过渡 effect**

在 `src/App.tsx` 中 `customBgStyle` 定义（约 242 行）之前插入：

```tsx
  // 背景交叉淡入（渐变不可插值 → 新背景层 0.3s 淡入，旧背景垫底）
  const [displayedBg, setDisplayedBg] = useState(appBg)
  const [washBg, setWashBg] = useState<string | null>(null)
  const washKeyRef = useRef(0)
  useEffect(() => {
    if (appBg === displayedBg) return
    setWashBg(appBg)
    washKeyRef.current += 1
    const t = setTimeout(() => {
      setDisplayedBg(appBg)
      setWashBg(null)
    }, 350)
    return () => clearTimeout(t)
  }, [appBg, displayedBg])
```

- [ ] **Step 2: 根 div 应用新背景 + wash 层**

根 div（约 259-265 行）的 `background: appBg,` 改为 `background: displayedBg,`，并在该 div 内（TitleBar 之前）插入 wash 层：

```tsx
      style={{
        display: 'flex', flexDirection: 'column', height: '100vh',
        background: displayedBg,
        transition: 'background 0.3s ease, opacity 0.3s ease',
        position: 'relative',
        ...customBgStyle,
      }}>
      <div
        key={washKeyRef.current}
        className="app-bg-wash"
        style={{ background: washBg ?? 'transparent' }}
      />
      <TitleBar />
```

- [ ] **Step 3: wash 层样式**

`src/styles/theme.css` 末尾追加：

```css
/* 主题切换：新背景层 0.3s 淡入，形成墨色晕开换场 */
.app-bg-wash {
  position: absolute;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  animation: app-bg-wash-in 0.3s ease;
}

@keyframes app-bg-wash-in {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

（`prefers-reduced-motion` 全局规则会把动画时长归零，无需额外处理）

Run: `npm run build`，再 `npm run dev`
Expected: 构建成功；暗夜↔日间切换时背景墨色 0.3s 淡入换场（书架页与阅读页均生效）；自定义壁纸（图片）不受影响；无 z-index 遮挡问题（wash 层 `z-index:0`、`pointer-events:none`，内容正常可交互）
